# coderabbit

Central [CodeRabbit](https://docs.coderabbit.ai/configuration/central-configuration) configuration for every Crown-OS repository.

A repository that adds its own `.coderabbit.yaml` must set `inheritance: true`, or this file is ignored for it.

## Checking the effective configuration

Comment `@coderabbitai configuration` on any pull request to see the resolved
settings and which layer each value came from.
